## 📜 El Manifiesto del Creador: Mi Pasión por Azeroth

> *"Un nombre en Azeroth nunca es una simple combinación de letras. Es el peso de un juramento, la cicatriz de una batalla ganada a duras penas, el susurro de los ancestros en Mulgore o el eco de un yunque forjado en las profundidades de Khaz Modan."*

Este proyecto nació de una pasión profunda y sincera por el universo y el *lore* de **World of Warcraft**, un mundo que ha marcado incontables horas de rol, hermandades, historias compartidas y aventuras memorables.

Como jugador y entusiasta del roleplay, siempre sentí que la creación de un personaje comienza mucho antes de pisar el Bosque de Elwynn o los baldíos de Durotar. Comienza con una pregunta: **¿Quién es este héroe? ¿De dónde viene su apellido? ¿Por qué lucha?**

Demasiadas veces vemos generadores de nombres genéricos que mezclan palabras al azar sin respetar la cultura de cada raza. **WoW Forever Identity Suite** fue creada para solucionar esto:

- **Los Humanos de Ventormenta y Lordaeron** no llevan apellidos vacíos; llevan compuestos nobles que celebran la Luz, virtudes o su feudo de origen (*Vadoargénteo, Guardasol, Vientorruna*).
- **Los Enanos de Forjaz** honran el martillo, el granito y el clan en cada sílaba (*Barbapiedra, Bramamartillo, Forjapiedra*).
- **Los Elfos de la Noche (Kaldorei)** veneran a Elune con palabras poéticas en darnassiano sobre la luna, las sombras y los bosques milenarios (*Susurravientos, Cantoluna, Plumalunar*).
- **Los Orcos de Draenor y Durotar** se ganan su apellido en combate como hazañas de guerra que hacen temblar la tierra (*Martillomaldito, Gritoinfernal, Rompehuesos*).
- **Los Renegados (No-muertos)** arrastran nombres humanos quebrados por el dolor de la peste y la tumba fría (*Tumbanegra, Pestepudrida, Mortajasombría*).
- **Los Tauren de Mulgore** caminan en armonía con la Madre Tierra y sus tótems ancestrales (*Pezuñasangre, Tótembravo, Astafiel*).
- **Los Troles Lanza Negra** canalizan el vudú sagrado de los Loa y los ritos de caza selvática (*Lanzanegra, Dientevudú, Sombraselva*).
- **Los Gnomos de Gnomeregan** son pura chispa, engranaje y vapor excéntrico (*Chispatuerca, Girovapor, Muelleloco*).
- **Los Cielonatos (Elfos Azules)**, como homenaje a nuevas corrientes de rol fantástico, exploran los vientos celestes y las estrellas (*Cielonato, Formavientos, Alaceleste*).

Esta herramienta está hecha por un rolero, para roleros y amantes de este universo.

## ✨ Características Principales

### 1. ⚔️ Forja de Nombres y Linajes
- Generación de **nombres de una sola palabra** y **apellidos compuestos de una sola palabra** estrictamente apegados a las convenciones canónicas de Blizzard.
- **Motor Dual Inteligente:**
  - **IA Gemini 3.8 Flash:** Conexión con modelos avanzados de lenguaje para inventar nombres frescos con trasfondo, título honorífico y significado histórico.
  - **Motor Canónico Local (Offline):** Generador determinista completo integrado con cientos de raíces, prefijos y sufijos por raza que funciona sin internet ni cuotas.
- Filtros por raza (Alianza, Horda y Cielonatos), género, tono narrativo (Noble, Feroz, Críptico, Festivo, etc.), clase sugerida y personalización de prefijos/sufijos de linaje.

### 2. ✨ Oráculo de Rol: Clase & Raza
- Cuestionario inmersivo de **6 preguntas situacionales** basadas en dilemas morales, tácticas de combate y afinidades elementales en Azeroth.
- Algoritmo de afinidad que calcula tu compatibilidad porcentual con las clases del juego (Guerrero, Paladín, Cazador, Pícaro, Sacerdote, Chamán, Mago, Brujo, Druida) y te sugiere la raza ideal para encarnar ese rol.

### 3. 📜 Enciclopedia de Linajes & Requisitos
- Compendio visual con capitales, líderes, descripción histórica y filosofía onomástica de cada raza.
- Matriz completa de clases permitidas y detalles de trasfondo cultural.

### 4. 📖 Grimorio de Personajes (Guardado Local)
- Guarda tus identidades favoritas con un solo clic.
- Permite añadir **notas personalizadas de rol** (profesión, trasfondo, reino).
- Copia rápida al portapapeles y exportación en formato de texto / ficha de personaje.
- Almacenamiento persistente en `localStorage`.

### 5. 🔊 Inmersión Audiovisual Blizzard
- Efectos de sonido analógicos sintetizados con la Web Audio API (apertura de pergaminos, chasquidos de metal, monedas, campanas de logro) sin necesidad de cargar pesados archivos externos.
- Selector bilingüe instantáneo (Español 🇪🇸 / Inglés 🇬🇧).
- Diseño adaptativo enmarcado con ribetes góticos, sellos de facción y gemas de engarce.

## 🚀 Instalación y Puesta en Marcha

### Requisitos previos
- Node.js versión 20 o superior.
- npm o bun.

### 1. Clonar el repositorio
```bash
git clone https://github.com/DengnisR/wow-forever-identity-tools.git
cd wow-forever-identity-tools
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Configurar variables de entorno (Opcional para IA)
Copia el archivo de ejemplo:
```bash
cp .env.example .env
```
Agrega tu clave de Gemini obtenida en [Google AI Studio](https://aistudio.google.com/app/apikey):
```env
GEMINI_API_KEY="tu_clave_aqui"
```

### 4. Iniciar en modo desarrollo
```bash
npm run dev
```
Abre tu navegador en [http://localhost:3000](http://localhost:3000).

### 5. Compilar para producción
```bash
npm run build
```

## 🌐 Despliegue en Cloudflare Pages (Hosting Recomendado)

Este proyecto está optimizado para desplegarse de forma ultrarrápida y global en **Cloudflare Pages**:

1. Inicia sesión en tu panel de [Cloudflare Dashboard](https://dash.cloudflare.com/) y dirígete a **Workers & Pages**.
2. Haz clic en **Create application** > pestaña **Pages** > **Connect to Git**.
3. Selecciona tu repositorio: `DengnisR/wow-forever-identity-tools`.
4. En los ajustes de compilación (*Build settings*):
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
5. En **Environment variables** (Variables de entorno de producción):
   - Añade la variable: `VITE_GEMINI_API_KEY` con el valor de tu clave de Google AI Studio.
6. Haz clic en **Save and Deploy**.
7. ¡Listo! Cloudflare compilará y distribuirá tu aplicación a nivel mundial bajo una URL segura `https://wow-forever-identity-tools.pages.dev` (o con tu propio dominio personalizado).

*(Nota: También es compatible con cualquier hosting estático o Node fullstack como Render, Vercel o Netlify).*
